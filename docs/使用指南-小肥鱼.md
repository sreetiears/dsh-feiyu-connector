# 小肥鱼 · 使用指南（P0 已落地）

> 装的是什么：一个 DSH 插件 `feiyu-connector` + 一个角色预设「小肥鱼」。
> 现在能做什么：**看 B 站热点/视频/评论**（只读）+ **用大肥鱼人设陪你聊天** + **到点主动开口**（需要你在人设会话里开一次）。

---

## 一、三步用起来

### 1. 新建会话，选「小肥鱼」预设

侧边栏新建会话 → 预设选择器里选 **小肥鱼**（如果没看到，去 设置 → Agent preset 刷新一下；可以在那里设为默认）。

预设卡片选中后，这个会话里说话的就是大肥鱼：一次一两句、不用 Markdown、会有情绪。

### 2. 直接聊，它会自己查 B 站

试着说：

- 「今天 B 站有什么热闹的」→ 它会调 `bili_hot`
- 「看看排行榜前三」→ `bili_ranking`
- 「搜一下 XX 的视频」→ `bili_search`
- 「这个视频讲啥 BV1xxx」→ `bili_video`
- 「评论区在吵什么 BV1xxx」→ `bili_comments`

### 3. 它会自己找你（不需要设置）

**在「小肥鱼」会话里第一次说话之后，插件会自动开始心跳**：

- 首次 20 分钟后第一跳，之后约每 90 分钟一次（±15 分钟抖动）；
- 23:00–08:00 静默；每天最多 6 次；你正在说话/它正在干活时自动跳过；
- 到点它**不是打招呼**，而是真的去 `bili_hot` 看热搜、`bili_ranking` 看排行，挑一个感兴趣的再用 `bili_video`/`bili_comments`/`bili_search` 深入，然后像刷到好东西一样主动说 1~2 句（带链接）；没劲就回 `[不说]`。

想立刻验证或手动管理，任意会话里让它（或你自己）调用：

| 调用 | 作用 |
|---|---|
| `feiyu_heartbeat({action:"status"})` | 看哪些会话在跑心跳、下次几点、今天发了几次 |
| `feiyu_heartbeat({action:"debug"})` | 运行态诊断：事件有没有收到、agents 服务是否可用、每个 Agent 的状态/预设 |
| `feiyu_heartbeat({action:"fire", session_id:"<会话 id 前 8 位>"})` | 立刻投递一次（测试用；agent 正在跑时会排队到下一轮） |
| `feiyu_heartbeat({action:"arm"/"disarm", session_id:"..."})` | 手动开/关某个会话的心跳 |

> 验证心跳是否真的在工作：在「小肥鱼」会话里说完一句话后，调 `feiyu_heartbeat({action:"debug"})`，看 `turnStarts` 和 `presetMatches` 是否 ≥1、`armed` 是否 ≥1；再 `fire` 一次就能立刻看到它去查 B 站。

> 也可以照旧在「小肥鱼」会话里说「以后每天 9:30、14:30、21:30 主动找我」——那是走内置定时任务（侧边栏「自动化任务」可见），和心跳可以并存也可以二选一。

## 二、能力边界（重要）

| 能做 | 不能做 |
|---|---|
| 读热搜、排行榜、搜索、视频详情、评论 | ❌ 发评论 / 发动态 / 投稿 |
| 用人设聊天、主动开口 | ❌ 读 X（推特），本机网络不可达且你暂无账号 |
| 定时任务（在自动化任务页管理） | ❌ 关机/退出 DSH 后主动发消息 |

- **主动开口依赖 DSH 运行**：DSH 关着不会发；定时任务重开时只补最近一次错过的。
- **心跳状态存在内存里**：DSH 重启后心跳计时会清空，在「小肥鱼」会话里再说一句话就会重新武装（不需要重新配置）。
- **没有写权限**：P1 才做「草稿 → 你确认 → 发评论」，P0 它只会说自己只会看。
- 数据来自 B 站公开接口，不带登录态，所以看不到需要登录才有的内容（私信、关注流等）。

## 四、已知限制 / 下一步

1. **主动开口要在人设会话里开一次**（见 §1.3）。原因：定时消息只能投递给"创建它的那个会话"，而 P0 没有替你在后台新建人设会话的能力。P1 可以做一个 companion 模块，由插件自己在后台开人设会话并唤醒——那样就变成真正"不用管，它自己会来"。
2. **写操作未做**：P1 加 `bili_comment_draft` / `bili_comment_publish`（草稿 + 一次性确认 token + 每日上限 + 审计日志）。
3. **X 未接入**：需要账号 + 代理；二选一：官方 API（付费）或 Grok OAuth 搜索（社区插件 `dsh-grok-xsearch` 走这条路）。
4. **人设可换**：`feiyu-connector/cordis.patch.yml` 里 `persona.prefix` 换文本即可（改完要重新 enable 一次插件）。当前正文来自 `persona/dafeiyu.md`（aureth-labs/dsh-aurabot-qq，MIT）。

## 五、卸载 / 回滚

- 面板：设置 → 插件 → 找到 `feiyu-connector` → 停用（或在插件管理器里 `remove_bundle`）。
- 代码在 `feiyu-connector/`，删掉即可；定时任务在「自动化任务」页删除。
